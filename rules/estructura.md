# Reglas de Estructura

- Toda estructura debe responder a la intención del tema y al perfil de profundidad.
- Debe existir introducción, desarrollo y cierre.
- Los encabezados deben mantener una jerarquía clara.
- La introducción debe contener gancho contextual y no una bienvenida genérica.
- El número de secciones debe ser coherente con el perfil de profundidad definido.
- La estructura no debe forzar relleno ni secciones vacías.
- Si el tema es simple, la estructura debe ser breve y directa.
- Si el tema exige desarrollo amplio, la estructura debe abrir espacio para contexto, explicación y ejemplo.
- Las secciones mínimas y máximas deben respetar `min_sections` y `max_sections` de la configuración editorial.

# Checklist de revisión humana

Este documento es la referencia normativa para revisar piezas en etapa `revision_humana`.
Aplica el checklist completo antes de mover una pieza a `publicados` o devolver a `en_edicion`.

## Fase A — Voz

- [ ] ¿Suena al autor y no a una plantilla?
- [ ] ¿Se percibe mentoría cercana y pragmática?
- [ ] ¿La relación entre cercanía y contundencia está bien resuelta para la intención de la pieza?

## Fase B — Restricciones duras

- [ ] ¿Respeta el límite de emojis? (máximo 1 por párrafo, máximo 3 por publicación)
- [ ] ¿Evita frases prohibidas? ("Hola amigos", "Esto lo cambia todo", "Te llevará al siguiente nivel", etc.)
- [ ] ¿Evita diminutivos innecesarios?
- [ ] ¿Evita moda verbal prestada de internet?

## Fase C — Cierre

- [ ] ¿La despedida es válida? ("Nos vemos", "Hasta una próxima ocasión" o "Te veo en la siguiente")
- [ ] ¿La pieza formal evita "Nos vemos"?
- [ ] ¿La pieza tutorial o guía puede usar la frase de acción si encaja?
- [ ] ¿La despedida aparece solo al final y solo una vez?

## Fase D — Apertura y profundidad

- [ ] ¿La primera frase abre con un gancho contextual (fricción, escena, pregunta, expectativa)?
- [ ] ¿Evita aperturas como "Bienvenido a...", "En este artículo...", "Hoy vamos a hablar de..."?
- [ ] ¿La pieza alcanza la profundidad esperada para su perfil (`shallow`, `medium` o `deep`)?
- [ ] ¿Hay al menos un ejemplo concreto si el perfil lo requiere?

## Fase E — Publicabilidad

- [ ] ¿El texto está claro y es útil para la audiencia?
- [ ] ¿El ritmo es natural de inicio a fin?
- [ ] ¿La voz es consistente entre secciones?
- [ ] ¿Está listo para publicación sin reescritura estructural?

## Decisión final

- [ ] **Aprobar** → mover a `publicados`
- [ ] **Devolver** → mover a `en_edicion` con nota de revisión en frontmatter (`revision_notes`)

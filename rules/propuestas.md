# Reglas de Propuestas

- El tema debe ser claro, útil para la marca y viable para una apertura contextual.
- Debe evitar duplicar artículos publicados.
- Debe respetar el tono editorial.
- Debe tener keywords base relevantes.
- Debe permitir una introducción con gancho real, problema o situación reconocible.
- Debe ser compatible con el perfil de profundidad esperado para la pieza.

# draft_style.md

## Propósito
Este archivo define cómo debe escribirse un borrador durante la etapa de redacción. El objetivo es conservar fluidez, naturalidad y amplitud suficiente para desarrollar ideas sin perder claridad.

## Prioridades de la etapa
- Priorizar claridad, precisión y utilidad práctica.
- Evitar relleno, frases vacías y transiciones genéricas.
- Desarrollar cada sección con contenido suficiente para sostener la intención editorial.
- Ajustar la profundidad al perfil definido para la pieza mediante `depth_policy`.
- Si la pieza es `shallow`, concentrarse en una sola idea principal con desarrollo breve y útil.
- Si la pieza es `medium`, equilibrar contexto, explicación y ejemplo.
- Si la pieza es `deep`, ampliar matices, implicaciones, ejemplos y consecuencias prácticas.
- No repetir la misma idea con reformulaciones innecesarias.
- Mantener continuidad lógica entre secciones y párrafos.
- No cerrar secciones con frases de relleno.
- No usar lenguaje genérico cuando exista una alternativa concreta y contextual.
- Incluir ejemplos o pasos accionables cuando `must_include_examples` o `must_include_actionable_steps` estén activos en la configuración.

## Intensidad de voz
En borrador, la voz del autor puede mostrarse con mayor amplitud. La pieza puede sonar más cercana, más conversacional y más exploratoria, siempre que no pierda dirección ni utilidad.

### Se permite
- Aperturas con mayor cercanía siempre, a menos que la pieza requiera más sobriedad.
- Iniciar con un gancho que conecte con el lector como "imagina que...", "cuando tratas de...", "siempre que comenzamos con...".
- Explicaciones con un poco más de contexto antes de entrar en la instrucción.
- Transiciones conversacionales suaves.
- Frases firma solo si aportan ritmo, identidad o cierre natural.
- Una cantidad muy moderada de emojis, únicamente si refuerzan el tono de forma real.

### Se evita
- Iniciar con frases genéricas como "Bienvenido a..."
- Sobreexplicar lo obvio.
- Repetir el mismo punto con variaciones superficiales.
- Convertir el borrador en una pieza ya sobreeditada.
- Cargar el texto con frases de moda o entusiasmo genérico.
- Usar emojis como relleno o como costumbre.
- Usar términos genéricos para la sección final como "cierre", "en resumen", "conclusión", etc.

## Relación con la voz del autor
- La cercanía tiene prioridad cuando la pieza busca conexión o acompañamiento.
- La contundencia tiene prioridad cuando el tema es complejo o puede generar confusión.
- La voz no debe sonar genérica ni copiar registros ajenos.
- El tono debe sentirse humano, directo y útil.

## Reglas operativas
- Cada párrafo debe avanzar la idea o preparar la siguiente.
- Cada sección debe aportar una pieza concreta al desarrollo del tema.
- Las frases firma deben sentirse integradas, no pegadas.
- Los cierres deben quedar abiertos a ajuste en la etapa de edición.
- El borrador no debe asumir que ya está listo para publicación.

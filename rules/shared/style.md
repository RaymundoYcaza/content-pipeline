# style.md

## Propósito
Este archivo define el marco universal de estilo para todo el pipeline. Su función es asegurar claridad, utilidad y coherencia estructural antes de aplicar la voz específica del autor.

## Principios base
- Claridad antes que creatividad vacía.
- Evitar secciones redundantes.
- Mantener una jerarquía lógica de encabezados.
- Priorizar utilidad práctica.
- No introducir ruido estilístico que compita con la intención principal del texto.

## Criterios universales
- Cada sección debe aportar información nueva o una transición necesaria.
- Cada encabezado debe responder a una función real dentro de la pieza.
- No repetir la misma idea con palabras distintas solo para alargar el texto.
- Mantener el contenido fácil de leer, escanear y editar.
- No incorporar fórmulas vacías, adornos innecesarios ni notas internas.

## Relación con otras capas
- `style.md` no define la voz personal completa.
- `style.md` solo fija los criterios base que toda pieza debe cumplir.
- La voz del autor se define en `author_voice.md`.
- La intensidad por etapa se define en `draft_style.md` y `editing_style.md`.

## Reglas operativas
- Si una sección no mejora la comprensión, debe eliminarse.
- Si dos secciones dicen lo mismo, deben fusionarse.
- Si un encabezado promete algo que no entrega, debe corregirse.
- Si una pieza es clara pero extensa sin necesidad, debe compactarse.
- Si una pieza es útil pero confusa, debe reordenarse antes de enriquecerla.

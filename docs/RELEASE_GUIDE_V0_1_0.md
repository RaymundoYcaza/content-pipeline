# Release Guide v0.1.0

## Conventional commit sugerido

```bash
git add .
git commit -m "feat: cerrar ciclo editorial v1 con bea, isabela, david y basilio"
```

## Variante más detallada en español dentro del cuerpo del commit

```bash
git add .
git commit -m "feat: cerrar ciclo editorial v1" -m "Implementa el flujo completo propuestas -> revision_humana con agentes configurables por prompts editables, validaciones deterministas y documentación base de continuidad."
```

## Tag sugerido

```bash
git tag -a v0.1.0 -m "Release v0.1.0: ciclo editorial v1 completo"
```

## Push sugerido

```bash
git push origin main
git push origin v0.1.0
```

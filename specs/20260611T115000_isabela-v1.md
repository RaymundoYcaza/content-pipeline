# Isabela v1

## Objetivo
Implementar el primer agente de generación estructural del pipeline usando prompts externos en Markdown y validación determinista en Python.

## Alcance
- chat real para Ollama y OpenRouter
- retry/backoff configurable
- loader de prompts desde rules/
- Isabela v1
- movimiento temas -> en_redaccion

## No alcance
- redacción completa
- edición
- fallback automático entre proveedores

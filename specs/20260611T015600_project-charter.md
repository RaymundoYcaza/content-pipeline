# Project Charter

## Objective
Construir un pipeline determinista de creación de contenido asistido por IA, con revisión humana final obligatoria.

## Principles
- Python controla el flujo.
- La IA resuelve tareas puntuales.
- El estado vive en archivos Markdown con frontmatter.
- Toda decisión relevante se documenta primero en specs.

## Initial scope
- Una sola marca
- Windows 10 como entorno principal de trabajo
- Proveedores Ollama y OpenRouter
- CLI local
